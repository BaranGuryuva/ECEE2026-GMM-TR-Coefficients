# ECEE2026-GMM-TR-Coefficients
Coefficients of PGA, PGV and T = 0.2, 1.0s for the GMM-TR model proposed in "An Updated Ground-Motion Model for Türkiye: Advancements in Horizontal Component PGA, PGV, and Spectral Predictions", by Özkan Kale, Mustafa Abdullah Sandıkkaya, and Baran Güryuva

It should be noted that the coefficients are not finalized and subjected to change in the near future.
